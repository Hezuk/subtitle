⚙️ Internal Functions
run_pipeline() → Phase 1: 음성인식 → 번역 → QA검토
run_encode() → Phase 2: ffmpeg 자막 번인
translate_with_gemini() → 전체 블록 일괄 번역
review_with_gemini() → QA 검토 + RETRANSLATE 판정
retranslate_with_gemini() → 단건 재번역 (에디터)
parse_srt() → SRT → [{idx, timestamp, text}]
segments_to_srt() → Whisper segments → SRT
srt_to_vtt() → SRT → WebVTT (player용)
wrap_subtitle() → 42자 초과 줄 2줄 분할
fmt_elapsed() → 초 → "1분 23초" 포맷
